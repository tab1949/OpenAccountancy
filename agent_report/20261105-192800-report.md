### 1) 协议层移除新建账套目录参数
- 文件：`src/common/contracts.ts`
- 变更：`CreateBooksetPayload` 删除 `directoryPath`，仅保留：

### 2) 主进程新建逻辑自动读取系统目录
- 文件：`src/main/main.ts`
- 变更：
  - 新增 `resolveBooksetDirectory(configuredPath)`：
    - 从系统设置 `db_storage_path` 解析目录
    - 若配置为空，返回明确错误提示

    1. 读取 `dbService.getConfiguredStoragePath()`
    2. 自动创建该目录

  - UI 改为只展示提示：
    - “自动使用系统设置中的 SQLite 数据目录”
