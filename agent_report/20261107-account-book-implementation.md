# 行动报告：科目表和账簿

## 实现
- 账簿菜单新增“科目 / 科目表”，并实现科目新增、删除、修改、查找和凭证明细映射。总账科目的类别和方向分别来自准则文档和用户提供的 CSV；既有总账科目名称保持不变。
- 明细科目存储于各账套数据库；按账套科目结构校验编码，禁止删除被引用或有下级的科目，禁止更改此类科目的编码。
- 已记账凭证是账簿计算的数据源：实现科目总账、明细账、日记账和余额表，支持期间筛选、累计和期初余额、总账筛选及 PDF、XLSX、CSV 导出。余额表合计仅统计总账科目。
- 记账前要求将自由文本明细映射到末级科目；跳过已结账期间的凭证，并报告记账数量。映射基于总账编码和明细文本，确认后不可修改，界面会提示其影响范围。
- 账套启用期之前的余额按零计算；无法确定启用期间、期间重叠或记账日期不属于唯一期间时明确报错。新增使用说明见账簿需求文档。
- 新增 ExcelJS 及其依赖用于 XLSX 导出；保留工作区原有未提交修改。

## 使用限制
- 已确认的明细映射目前不可修改；确认前必须核对，避免把历史凭证映射到错误科目。
- 尚未实现需求文档中“无记账权限时提交上级审批”的流程；当前项目原有权限和记账流程未提供该审批机制。
