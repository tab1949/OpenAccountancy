# Account Book 关于账簿的描述
## Account Sheet 科目表
科目表中列举了当前账套可用的所有科目，包含科目代码和科目名称。  
**一级科目/总账科目** 由建立账套时指定的会计准则决定，不可更改，但可以为其设置多级明细科目。例如“1012 其他货币资金”为一个总账科目；  
**明细科目** 允许用户在某一**总账科目**或**明细科目**下自定义科目代码和科目名称。系统默认允许设置4个科目级次，编码长度分别为4-2-2-2，在新账套首次结账前允许增加级次和编码长度，首次结账后则不允许更改。例如“101201 其他货币资金-支付宝”是一个合法的二级科目，“22210101 应交税费-应交增值税-进项税额”是一个合法的三级科目。
```
新增 删除 修改 查找
|序号|级次|科目编码|科目名称|科目类型|余额方向|
|1   |1  |1001   |库存现金|资产    |借      |
...
```
点击“新增”后，弹出窗口，在窗口中，先选定一个已有的科目，然后为新的科目设置编码、名称、余额方向。填写/设置完成后，生成一个新的科目编码，并将新的信息增加到科目表中对应位置（上级科目下方，并且按级次增加缩进）；  
点击“删除”后，将表中所有总账科目置为灰色不可访问，然后当光标悬停到可删除的科目行时将这一行的背景色设为红色，此时如果点击这一行则弹窗确认删除；  
点击“修改”后，将表中所有总账科目置为灰色不可访问，其他所有单元格的“科目编码”“科目名称”变为编辑框，“科目类型”变为select（小企业准则：资产/负债/所有者权益/成本/损益；企业准则：资产/负债/共同/所有者权益/成本/损益），“余额方向”可选择“借/贷/借或贷”；  
科目余额方向统一为“借”“贷”或“借或贷”；准则中的“借(可贷)”“借/贷”“贷(可借)”等双向描述均显示为“借或贷”，旧账套的明细科目方向也会自动迁移。
点击“查找”后，弹出窗口，在编辑框中输入科目编码或者科目名称，点击确认后在表格中搜索含有相关内容的行，点击取消关闭搜索窗口。
## Account General Ledger 科目总账  
可查询、查看、导出PDF/XLS/CSV。  
查询时选定起止期间（例如：2026年01期-2026年02期），查得总账。  
查询完成后，可选择总账科目，查看相应的账表。  
```
|序号|期间   |摘要    |借方  |贷方 |方向|余额 |
|1  |       |期初余额 | 0.00| 0.00|  平| 0.00| （白底）
|2  |2026-01|本月合计 | 1.00| 0.00|  借| 1.00| （红底）
|3  |2026-01|本年累计 | 1.00| 0.00|  借| 1.00| （蓝底）
|4  |2026-02|本月合计 | 9.00| 0.00|  借|10.00| （红底）
|5  |2026-02|本年累计 |10.00| 0.00|  借|10.00| （蓝底）
...
```
“方向”根据科目的不同，可以为平/借/贷。  
“本月合计”“本年累计”行自动生成，分编为浅红背景和浅蓝背景。

## 当前实现说明
- 账簿根据账套内当前状态为“已记账”的凭证实时计算；修改或删除未结账期间的已记账凭证后，账簿随反记账结果重新计算。
- 启用期间之前的期初余额按零计算；后续期间的期初余额承接此前已记账分录的累计余额。查询起始期间不能早于启用期间。
- 原有凭证的自由文本明细需要在科目表中映射到末级明细科目；同一总账科目下的同名明细共用一项映射。确认映射后不可修改，请确认目标科目后再提交；未映射的明细不能记账，相关明细账和包含明细科目的余额表也不能查询。
- 已被映射使用的明细科目不能删除或修改编码，也不能继续添加下级；有下级的科目不能删除或修改编码。总账科目不可修改或删除。
- 科目余额表显示全部级次时，合计只统计总账科目，避免重复累计。导出支持 PDF、XLSX、CSV；XLSX 为 Excel 格式，CSV 使用单行完整列名。
- 科目余额表数值为零时在页面及 PDF 中显示为空白，XLSX 使用数字格式隐藏零值但保留原始数值；CSV 不支持显示格式，仍导出 `0.00`。
