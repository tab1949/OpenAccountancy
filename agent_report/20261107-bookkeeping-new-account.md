# 行动报告：记账时新建科目

## 修改
- 记账发现未关联凭证明细时，提供“新建科目”按钮，不再要求在该页面选择映射或前往科目表。
- 抽取并复用科目表新增表单，预填凭证总账科目和明细名称；可在该总账科目范围内选择上级科目。
- 新建科目和关联凭证明细由主进程在同一事务中完成；保存失败或关联失败时回滚并显示错误，多项明细依次处理后重新点击记账。
- 同一账套、同一总账科目下的相同明细自动复用关联；若新增时修改预填名称，原明细和新名称都关联到该科目。明细建议也包含已关联名称，不覆盖已有名称关联。
- 更新记账说明，保留已有未提交修改。
