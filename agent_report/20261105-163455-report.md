# 行动报告（2026-11-05 16:34:55）

## 目标
落实以下前端改造：
1. 基于 `authSession.permissions` 做菜单与按钮可见性控制。
2. 补充“登录失败锁定/次日解锁”的交互提示。
3. 微调“用户-设置”页面：按账户类型展示不同内容；所有账户都显示“修改密码”入口；管理员/主管显示账户列表与右侧“创建用户”按钮（弹窗新建）；记账员不显示账户列表。

## 实施内容

### 1) 权限可见性控制
- 文件：`src/renderer/App.tsx`
- 新增权限映射与判定：
  - `navPermissionMap`
  - `hasPermission(...)`
  - `canAccessPath(...)`
  - `canManageTargetUser(...)`
- 影响：
  - Sidebar 二三级菜单：无权限的菜单项不再显示。
  - 路由防护：若直接访问无权路径，工作区显示“无访问权限”占位页。

### 2) 登录锁定提示细节
- 文件：`src/renderer/App.tsx`
- 在登录页新增状态：`lockedToday`
- 行为：
  - 当登录返回“今日登录尝试已达上限”时，显示“当前账号已锁定，次日将自动解锁后可重新登录”。
  - 锁定当日禁用登录按钮。

### 3) 用户-设置页面按角色分层
- 文件：`src/renderer/App.tsx`
- 通用内容：
  - 所有角色显示“账户安全”卡片，包含“修改密码”入口（跳转到账户找回流程）。
- 管理员/主管：
  - 显示“账户列表”。
  - 在“账户列表”右侧显示“创建用户”按钮。
  - 点击后弹出“新建账户”窗口，内容沿用原“新建账户”区域（用户名、显示名、角色、初始密码、权限勾选）。
  - 支持 ESC 关闭弹窗。
- 记账员：
  - 不显示账户列表，仅显示个人安全设置说明。

### 4) 样式补充
- 文件：`src/renderer/index.css`
- 新增/调整：
  - `.form-grid select`
  - `.settings-password-panel`
  - `.user-list-header`
  - `.modal-backdrop` / `.modal-card` / `.modal-actions`
  - 响应式适配下 `.user-list-header`
