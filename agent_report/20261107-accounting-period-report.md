# 行动报告：当前会计期间

## 修改
- 打开账套后，在工具栏账套按钮右侧显示当前日期和会计期间；点击可打开日历并选择日期。
- 按账套 `fiscal_periods` 的起止日期匹配所选日期，将日期及对应期间保存到账套元数据。日期无效、没有匹配期间或匹配多个期间时拒绝切换。
- 使用 `CurrentAccountingPeriodContext` 和 `useCurrentAccountingPeriod` 向渲染进程组件共享当前日期、期间与切换方法；账套关闭、切换以及期间设置变化后同步刷新。
- 旧账套尚无选定日期时，优先使用当前期间内的本地今天，否则使用期间开始日。
