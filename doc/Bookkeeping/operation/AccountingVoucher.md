# Operations of Accounting Vouchers 关于记账凭证的操作
## 1. Fill 填制
1. 可选择提供附件（原始凭证）。如果涉及的分录需要有凭证提供，则强制要求提供附件。原始凭证可以是PDF/JPEG/PNG/...  
2. 每张凭证都有11行，无论是否全部使用。如果仅用一部分，剩下的行留空。
3. 填写时，需要先填写摘要，摘要填写后，依次开放总账科目和明细科目的填写。
4. 填写总账科目时，必须选择系统内置的选项，可用选项由账套所使用的会计准则决定。点击总账科目格时，下方弹出检索框，提供科目编码/科目名称两种检索方式。
5. 明细科目的填写方式由总账科目决定。如果总账科目有固定的二级分录/三级分录，则仅允许从提供的选项中选择。否则，允许自行填写，并在填写时提示以往在该总账科目下用过的分录供选择。
6. 填写借贷方发生额。在分录完成后开放。每行只能在借方/贷方中选择一者填写，在任何一栏填写金额后另一栏自动禁用，除非删除填写的内容。
7. 每填写完成一行，都在下方“总计”中显示自动计算的借方/贷方总发生额。
8. 当填制凭证完成，如果借贷平衡，则自动填写大写金额，并显示保存凭证按钮，否则红字警告“当前借贷不平衡”
9. 点击保存凭证后，后台存入数据库
## 2. Query 查询
提供检索方式：
1. 按时间范围：可通过日历选择时间范围，或通过固定选项“本月”“近3天”“近7天”“近30日”“近90日”“上周”“上月”
2. 按凭证号：提供月份和凭证号/凭证号范围
3. 模糊搜索：输入关键词，从‘1’中选定的时间范围内的凭证中，在这些凭证的“摘要”中查找关键词，输出包含关键词的所有凭证

输出：
1. 输出结果为一个可排序的表格。如果没有检索结果，则只显示表头而没有内容。
2. 表头依次为：日期，凭证号，金额，详情。前三者可作为排序依据，“详情”列全部显示为可点击的“查看”，点击后弹窗显示凭证详情。
## 3. Edit 编辑
- 在‘2.查询’中检索到的凭证，点击“查看”后弹出的预览窗中包含一个“编辑”按钮。
- 点击按钮后，如果是当期凭证，则直接开放编辑，编辑时的规则同“1.填制”。
- 如果是往期凭证且已经记账但未结账，则弹窗警告“您正在尝试反记账，确认则表示您知晓相关风险。修改该凭证后关联的账目将会自动重新计算。”。
- 若已结账，则直接提示“该账期已结账，无法修改”。
## 4. Remove 删除
- 在‘2.查询’中检索到的凭证，点击“查看”后弹出的预览窗中包含一个“删除”按钮。
- 点击按钮后，如果是当期凭证，则警告“您确认删除该凭证吗？”。
- 如果是往期凭证且已经记账但未结账，则弹窗警告“您正在尝试反记账，确认则表示您知晓相关风险，并删除该凭证。删除该凭证后关联的账目将会自动重新计算。”。
- 若已结账，则直接提示“该账期已结账，无法删除”。
