# General Operations 一般操作
## Entering the System 进入系统
启动App后，打开登入页面，根据是否存在数据库文件，
- （没有数据库）初始化：首次使用系统时，进入初始化设置。  
首先设置数据库存储的路径，后台初始化一个新的数据库  
然后设置管理员账户，需要提供用户名、密码、3个自定义密保问题
设置完成后，进入首页
- （有数据库）登录：输入用户名和密码，每天允许尝试5次，校验通过后进入首页
- （有数据库）找回账户：填写设置账户时提供的3个密保问题的答案，全部正确后显示用户名，并要求设置新密码  
**密码和密保问题的答案使用SHA512存储于数据库**  

用户有三种权限级别：
1. 管理员，可以在不经过审批的情况下全权访问整个系统
2. 账务主管，可以全权访问自己管理的所有账套
3. 记账员，可以访问自己有权访问的账套，但敏感操作需要账套主管审批  

管理员登入系统后可以创建主管账户和记账员账户，并为其分配权限；  
账套主管进入系统后可以创建记账员账户并为其分配权限；  
记账员登入系统仅可管理自己的账户密码、访问有权访问的账套、进行授权的操作。  
进入系统时不会显式指定用户类型，但是输入的账号密码会在后台自动匹配账户类型，并在成功登录后提供相应的内容。
## Main Window 主窗口
登入完成后，关闭登入页面，启动主窗口。  
整个系统采用淡灰色作为主色调，不支持切换主题。  
### Toolbar 工具栏
主窗口顶部具有工具栏。  
工具栏分为两种状态（未打开账套/已进入账套），  
未打开账套时：  
```
|Logo(主页)|账套          |搜索...  | 帮助|用户|  
           +-新建账套                    +-退出 
           +-打开账套                    +-设置   
           +-关闭账套  
           +-导出账套  
           +-导入账套  
           +-参数设置...
```
搜最近账套、帮助、设置项。  
已打开账套时：  
```
|Logo(主页)|账套:xx公司-2026年11期-未结账|待办（0）|搜索... |帮助|用户|  
           +-新建账套                   +-待审核凭证            +-退出 
           +-打开账套                   +-待过账凭证            +-设置   
           +-关闭账套                   +-待结转损益/待结账  
           +-切换账套                   +-银行未对账  
           +-导出账套                   +-备份提醒  
           +-导入账套                   +-系统消息  
           +-参数设置...
```
此时搜索工具可以搜菜单命令、凭证号、摘要、科目、往来单位等，并可直接跳转到 sidebar 对应模块。
此时出现“待办”栏，在未打开该选项卡时，在括号中用红字显示待办事项数。
### Sidebar 侧边栏
打开账套前，侧边栏为禁用状态，打开账套后侧边栏可用。
侧边栏包含了所有的业务入口。
```
----+----+
凭证|	 | (录入、查询、审核、过账...)
----+    |
账簿|	 | (总账、明细账...)
----+    |
往来|	 | (应收、应付、核销、对账、账龄...)
----+    |
出纳|	 | (日记账、银行对账、余额调节表、扎账...)
----+    |
期末|	 | (调汇、结转损益、自动转账、对账、结账/反结账...)
----+    |
报表|	 | (资产负债表、利润表、现金流量表、自定义报表...)
----+    |
设置|	 | (科目、凭证类别、币种汇率、辅助档案、期初...)
----+----+
```
上面描绘的侧边栏中，左侧的一列一级选项固定在MainWindow左侧，右边的二级三级选项卡栏在没有选择一级选项时为空，在点击了一个一级选项后，在其中显示二级选项和三级选项（已折叠），点击了一个三级选项后，MainWindow的工作区显示相应业务的内容。  
需要注意的是，示意图中的二级选项仅供说明参考，实际开发时具体的选项不一定和示例图相同。
