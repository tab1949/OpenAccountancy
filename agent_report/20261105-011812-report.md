## Trigger
- User request: `npm run dev` 时无法安装 Electron binary。

## Investigation
1. Reproduced issue with `npm run dev`.
2. Confirmed key error:
   - `Downloading Electron binary...`
   - `TypeError: fetch failed`
   - `Error: Electron failed to install correctly...`
3. Confirmed binary missing:
   - `node_modules/electron/dist/electron.exe` => `False`
4. Confirmed project had no `.npmrc` for Electron mirror.

## Fix Applied
1. Manually installed Electron binary with mirror:
   - Set `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`
   - Ran `npx install-electron --no`
   - Verified `node_modules/electron/dist/electron.exe` exists (`True`)
2. Persisted mirror configuration at project level:
   - Added `.npmrc`
   - Content: `electron_mirror=https://npmmirror.com/mirrors/electron/`

## Validation
- Re-ran `npm run dev` and confirmed no longer reports:
  - `Electron failed to install correctly`
- Build chain remained healthy from previous checks.

## Notes
- If `node_modules` is removed in future, project-level `.npmrc` keeps Electron download on the mirror path to reduce fetch failures.
