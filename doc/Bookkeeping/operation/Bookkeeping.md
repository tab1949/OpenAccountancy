# Operations of Bookkeeping 关于记账的操作
## Bookkeeping 记账
在记账页面中，可以勾选未记账凭证，勾选后点击“记账”按钮可提交记账申请，如果账户有权限则直接尝试记账，无权限则等待上级审批。  
当后台进入记账流程后，将会进行以下操作：  
1. 检查选中的每张凭证所属期间是否结账，如果已经结账则弹出警告提示该凭证所属期间已结账无法记账，然后继续检查下一张凭证，依此类推直到所有凭证都检查完成；
2. 检查完成后，将所有可记账凭证按照期间由旧到新、凭证号由小到大的顺序排好，然后将凭证中的内容（摘要、科目、借方、贷方）写入科目明细账（为所有科目记明细账。如果有新的二级三级等明细科目，则弹窗提示“是否将xx（科目名称）添加到科目表中？”，然后由用户设置科目代码）和科目日记账（按一级科目记日记账）；
3. 记账完成后，弹窗提示“已记账xx个凭证，共xx期，xx个总账科目，xx个明细科目。”；
4. 可在“账簿”页面查询、查看、导出记录的内容。

记账发现尚未关联的凭证明细时，点击“新建科目”，在新增科目窗口中默认填入凭证的总账科目和明细名称，补充科目编码等信息后保存。新建和关联在同一事务内完成；如有多项明细，依次处理后再次点击记账。此后同一账套、同一总账科目下名称相同的凭证明细自动使用该关联，不同总账科目的同名明细互不影响。若修改预填的科目名称，原凭证明细名称和新科目名称均关联到该科目；新名称如已关联其他科目则不能保存。填制凭证时可从明细建议中选择已关联的名称。

## 撤销记账
- 在“已记账凭证”区域选择未结账期间的凭证，点击“撤销记账”并确认警告后，凭证恢复为未记账状态，相关账簿和余额重新计算。
- 已结账期间的凭证不可选择。若提交时任一凭证已结账、状态已变化或不存在，整批撤销失败，需刷新后重试。
