# 行动报告：凭证撤销记账

## 修改
- 在查询凭证详情中增加撤销记账操作，并在执行前显示警告确认。
- 在记账页面增加已记账凭证区域，支持选择未结账期间的凭证并批量撤销；已结账凭证不可选择。
- 撤销在主进程事务内重新检查凭证状态及所属期间，任一凭证无效则整批失败；成功后写入撤销日志，凭证恢复未记账状态，账簿根据状态重新计算。
- 操作后刷新列表，并在刷新失败时提示；更新凭证和记账操作文档。
